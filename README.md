# 🐍 SLITHER ROYALE – AI SNAKE ARENA

> A massive AAA-style snake battle royale game built entirely with Python + Pygame.

---

# 🎮 About The Game

SLITHER ROYALE is an intense fast-paced survival snake game inspired by classic snake arena games and battle royale mechanics.

Fight against dozens of intelligent AI snakes inside a gigantic arena filled with food, coins, powerups, glowing effects, shrinking danger zones, and cinematic gameplay.

Grow bigger. Eliminate enemies. Survive the shrinking arena. Become the ultimate snake champion.

# 🚀 Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/jatinprajapat40-crypto/slither.io.git
```

---

## 2️⃣ Install Dependencies

pip install pygame

---

## 3️⃣ Run Game

python main.py
